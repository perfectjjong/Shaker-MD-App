# b2c-unified Overview 탭 개편 — 설계 문서

- 날짜: 2026-08-16
- 상태: 형님 승인 (레이아웃 목업 포함)
- 목업: https://claude.ai/code/artifact/c46ad078-d726-4e6c-8743-935217563d4c
- 대상: `docs/dashboards/b2c-unified/index.html` (생성기: `b2c_unified_dashboard_generator.py`)
- 범위: **Overview 탭만.** 다른 탭(Channel/Product/Supply vs Demand/WOS/Price/Detail)은 변경 없음.

## 1. 목적

Overview를 "숫자 나열"에서 **경영 브리핑형**으로 전환한다. 열자마자 "이번 주 사업이 좋은가/나쁜가 + 왜 + 무엇을 해야 하나"가 보이게 한다.

확정된 요구:
- **YoY 비교 최우선** (형님 강조: "연간 동기 대비가 정말 중요")
- WOS/재고 위험 신호, Sell-Thru vs Sell-Out 갭, 이상신호 자동 하이라이트 포함
- **비교 연도 선택기** (예: 2026 vs 2024 지정 비교)
- 레이아웃: **A(브리핑 밴드) + B(4분면 콕핏)** 조합
- So-What 밴드는 **하이브리드 생성 + 탈부착 가능** — 품질 보고 후 유지/제거 결정

## 2. 데이터 전제 (2026-08-16 원본 확인 완료)

내장 `_ALL.data[year]`에 4개년(2023~2026) × {raw(셀아웃), sellthru, stock, prices} 존재. **신규 데이터 소스 불필요.**

| 연도 | raw 주차 | 비고 |
|---|---|---|
| 2023, 2024 | W5, W9, W13… 스냅샷 ~12개 주 | 주 단위 YoY 정렬 **불가** → 월 단위 폴백 |
| 2025, 2026 | W1~W52 전 주차 | 주 단위 YoY 가능 |

- sellthru: 4개년 모두 존재 (2024: 2,113행 / 2025: 2,360행 / 2026: 9,758행)
- stock: 4개년 모두 `{weeks, channels, wos_thresholds_ir, wos_thresholds_or}` 구조

## 3. 화면 구조 (위→아래)

```
[필터 바]  기존 필터 유지 + "vs 연도" 선택기 신설
[🚨 So-What 브리핑 밴드]  ← SHOW_BRIEFING 플래그로 온/오프
[KPI 스트립 5개]
[4분면 그리드]
[▸ 상세 차트 (접이식, 기본 접힘)]  ← 기존 차트 보존
```

### 3.1 비교 연도 선택기
- Year 필터 옆 `vs YYYY` 드롭다운. 기본값 = 현재 연도 − 1
- 선택지 = `_ALL.years` 중 현재 연도 제외
- 비교 연도가 스냅샷 연도(2023/2024)면: 주 단위 비교 불가 → **월 단위 비교로 자동 전환** + 화면에 "월 기준 비교" 배지 표시 (거짓 정밀도 금지)
- 상태는 전역 `compareYear` 변수. 기존 `currentYear` 전환 로직은 그대로 두고, 비교 데이터는 `_ALL.data[compareYear]`에서 동일 필터로 계산

### 3.2 KPI 스트립 (기존 5개 전면 교체)

| # | KPI | 메인 값 | 강조(YoY) | 보조 |
|---|---|---|---|---|
| ① | 최신주 셀아웃 | 최신주 수량 | vs 비교연도 동일 주차 % | WoW % |
| ② | 월 누적 | 현재월 누적 수량 | vs 비교연도 동월 동기(同주차까지) % | MoM % |
| ③ | 연 누적 YTD | 최신주까지 누적 | vs 비교연도 동기 % | 비교연도 동기 수량 |
| ④ | WOS 위험 | 위험 건수(과잉+부족) | 과잉 n · 부족 m | 최다 위험 채널명 |
| ⑤ | ST−SO 갭 | 기간 갭률 % | 밀어넣기/결품 방향 라벨 | 갭 최대 채널명 |

- 제거: Active Channels, Unified Models (경영 판단 무관 메타 정보)
- YoY 계산 원칙: **동기 대비** — YTD·월누적은 비교연도의 "같은 주차까지"만 합산. 월 폴백 모드(스냅샷 연도)에서는 완결 월만 비교하고 진행 중인 월은 "부분월" 표기
- ④ WOS 위험 판정: 기존 WOS 탭의 `wos_thresholds_ir/or` 임계치·신호 로직 재사용 (새 룰 작성 금지)
- ⑤ 갭률 = (기간 Sell-Thru 합 − Sell-Out 합) ÷ Sell-Out 합. 현재 적용된 필터(채널/카테고리 등) 반영

### 3.3 4분면 그리드

| 분면 | 차트 | 내용 |
|---|---|---|
| ① 좌상 | 주간 셀아웃 트렌드 | 현재 연도 바(채널 스택 유지) + 비교연도 라인 오버레이(점선). 월 폴백 시 월 단위 바+라인 |
| ② 우상 | 채널×카테고리 YoY 히트맵 | 증감률 색상 매트릭스(적=악화, 녹=개선). 셀 클릭 → 해당 채널+카테고리 필터 적용 (드릴다운) |
| ③ 좌하 | WOS 신호등 | 채널별 최신주 WOS: 과잉/주의/적정/부족 도트 + 핵심 사유 1줄. 클릭 → WOS 탭 이동 |
| ④ 우하 | ST vs SO 갭 | 채널별 ST·SO 병렬 바 + 갭률. +과대=밀어넣기, −과대=결품 위험 |

### 3.3.1 데이터 라벨 원칙 (2026-08-16 형님 지시)
- **모든 차트에 숫자 라벨 필수** — "차트 안에 숫자가 있어야 와닿는다"
- ① 트렌드: 바 상단에 주간 합계, 비교연도 라인 끝점에 값 표시
- ② 히트맵: 셀 안에 YoY % 숫자 (색만으로 끝내지 않음)
- ③ WOS 신호등: WOS 주수 숫자 명기 (도트 색 + "21주" 병기)
- ④ 갭 바: 바 끝에 ST/SO 수량 + 갭률 % 명기
- 기존 `chartjs-plugin-datalabels` 재사용. 라벨 겹침 시 우선순위: 합계 > 끝점 > 개별 세그먼트

### 3.4 So-What 브리핑 밴드 (하이브리드)
- **필터 미적용(초기 화면)**: 빌더(파이썬)가 생성 시점에 만든 문장을 `_ALL.briefing`으로 embed — 진단 1줄 + 권고 1줄
- **필터 적용 시**: JS 룰 기반 문장으로 실시간 전환. 룰(초안): 주간 YoY ±10%p 이상, WOS 위험 상위, 갭률 ±20% 이상 채널을 문장 템플릿에 조합
- `const SHOW_BRIEFING = true` 플래그 1개로 밴드 전체 제거 가능. **품질 검증 후 형님이 유지/제거 결정** (본 설계의 명시적 보류 사항)
- 빌더 문장 생성도 동일 룰 기반(파이썬)으로 시작. LLM/분석센터 연계는 본 설계 범위 외 (추후 확장 여지만 남김)

### 3.5 접이식 상세 섹션
- 기존 Overview 차트 중 Monthly Sales, Sales by Category(도넛), Category Weekly Trend를 `<details>` 접이식으로 이동 (기본 접힘). 제거 아님
- 기존 Weekly Sales Trend(채널 스택 바)는 4분면 ①이 대체 (채널 스택 유지 + YoY 라인 추가이므로 정보 손실 없음)
