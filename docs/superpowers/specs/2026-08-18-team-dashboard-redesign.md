# 팀장 대시보드 전면 재제작 스펙 (2026-08-18 형님 승인: "일단 만들고 조정")

원칙: 탭 1개 = 경영 질문 1개. 데이터가 먼저, 코멘트는 나중. 임원용 템플릿 복제 폐기 — 독립 빌더.
IR/OR 는 사업 구조가 달라 내용물이 다르다 (IR: 딜러 도매·BH 43%·ST=AR / OR: 리테일·eXtra 51%·가격전쟁).

## 탭 구성 (6)
1. **Summary** — 사업이 잘 돌아가는가: YTD·최근4주 YoY(2025 동기), 월별 SO 4개년 곡선+현재 마커,
   채널별 YoY 기여도, 카테고리 믹스(인버터 비중), 재고 총량+시즌 커버 시나리오
2. **Target** — RSM FCST 가 건강하게 진행 중인가: 채널별 ST 목표 vs 실적(수량·금액), 경과페이스,
   필요 런레이트(잔여일), **소화율(동기간 SO/ST)**, 재고 방향(월초 대비), 카테고리 목표 대비,
   판정 매트릭스(진도×소화×재고: 건강/밀어내기/판매실행/공급)
3. **Channels** — 채널 카드: 12주 스파크, 목표 페이스, 시즌 커버, WOS-8(임계 IR 8/16·OR 6/8), YoY,
   카테고리 믹스 / IR 고유: ST−SO 누적갭(여신), OR 고유: 가격갭 중앙값
4. **Inventory** — 잔여시즌 과부족(보수/중립/낙관), 모델 보충 후보(잔여수요−재고, WOS 긴급도 병기),
   과잉 모델(낙관에도 잔존), IR: IR_Others 재고 추적
5. **Price** — 채널×모델 갭(LG vs Gree→Midea→TCL), 갭 주간 추이(중앙값), 이탈 리스트(분포 기준:
   팀 중앙값 +20%p 초과 — 조정 가능 파라미터), 커버리지 진단(LG 라인업 축소 감지)
6. **Data** — 채널×주×카테고리 집계표 + CSV. 모델 원자료는 임원용(b2c-unified) 링크

## WOS vs 시즌 커버 (병기, 역할 구분)
WOS(최근 4주 속도) = 단기 운영·결품 경보 / 시즌 커버(잔여수요 대비) = 보충·소진 의사결정.
MOS 는 월마감 계열 어휘 — 주간 팀장 화면은 WOS 로 통일.

## 아키텍처
- `team_dashboard_builder.py` 신설 — 모든 계산은 **빌드 타임 파이썬** (JS 는 탭 전환·차트 렌더만).
- 재사용: role_data(슬라이스·정합), season, rsm_targets, price_position(+주간 갭 추이 확장), SSOT 일체.
- 출력: team-ir/ · team-or/ 교체 (URL 유지). role_build 는 담당자용 13개 전담으로 축소.
- 검산: 빌더가 기준(b2c-unified) 합과의 일치를 빌드 시 검증·페이지에 검산 메타 임베드,
  role_audit 는 그 메타로 팀장용 검사.
- 차트: Chart.js(기존 CDN), animation:false(범례 결함 회피), 에디토리얼 팔레트 준수.
- 결손=빈값(거짓 0 금지) · 정합조정 금지 · 모델명 v6 정본.
