방법론. 실적(2023~2026 상반기)=b2c-unified raw를 SSOT shared_category로 재분류(Split AC만, Inverter/On-Off). 2026 하반기 예측=채널별 상반기 실적 앵커 × 하이브리드 시즌 비율(이력 두꺼운 채널=자체 H2/H1, 얇으면 그룹으로 수렴: 최종=w·채널+（1−w)·그룹, w=n/(n+1.5)) × 그룹 월분포. 자세한 채널별 산식은 상단 🧮 예측 로직 탭 참조. 위스커=Worst~Best. ⚠️ 절대수준은 b2c 기준(OR은 or-monthly-psi 정본比 ~+4%), 7월 실데이터 부분(7/19)이라 하반기는 예측이며 확정치 아님.
하이브리드 승격 완료 — 무엇이 어떻게 바뀌었나
이전엔 시즌비율을 그룹 공통으로만 썼지만, 이제 이력이 두꺼운 채널은 자기 비율을 반영합니다.
✔ 채널별 : ① 2026 상반기 실측(레벨) ② H2/H1 비율도 이력 충분하면 채널 고유값 사용.
✔ 그룹 공통 : 월분포(7~12월 배분)는 잡음이 커서 그룹 평균 유지.

왜 그냥 채널값을 안 쓰고 '혼합'했나? 채널 이력이 2~3년뿐이라 이상치 1년이 예측을 폭발시킵니다(예: IR_Others On/Off 2025년 3.31배). 그래서 신뢰도 가중 혼합(shrinkage): 이력 두꺼우면 자기값, 얇으면 그룹값으로 자동 수렴. 이력 없는 채널은 100% 그룹값.

계산식 (하이브리드)

최종비율[채널·압축기] = w × (채널 자체비율) + (1−w) × (그룹비율)
w = n / (n + 1.5) n = 유효이력 연도수 (반기 base ≥ 80대인 해)
   n=0 → w=0.00 (그룹 100%) · n=1 → 0.40 · n=2 → 0.57 · n=3 → 0.67

H2월(m) = H1_2026실측[채널] × 최종비율_시나리오 × 월분포[그룹](m)
ML/Best/Worst 각각에 위 혼합을 적용. 채널 자체 ML=자기 이력의 최근가중, Best/Worst=자기 이력 최대/최소(유효연도 내). 3개년 뿐이라 w는 최대 0.67로 제한 — 그룹이 항상 최소 1/3 앵커.
