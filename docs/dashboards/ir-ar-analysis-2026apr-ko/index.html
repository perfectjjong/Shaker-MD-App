🔍 사업부별 결제 우선순위 분석

  1. AC↓↓ HA↑ 패턴: 동일 거래선이 HA 채권은 정상 결제하면서 AC만 연체 → AC 사업부의 credit 정책 약화 / 영업 push 부족 / 제품 판매부진 가능성. RSM 회의에서 사업부별 결제 우선순위 협상 필요.
  2. 갭 ≥ +50pp 계정: 단순 거래선 신용 문제가 아닌 사업부 구조 시그널. 회수팀 단독 대응 불가 → AC RSM + Credit Manager + 영업본부 합동 회의.
  3. AC↑ HA↓ 패턴 (역전): 일부 계정에서 발견 시 HA 사업부 회수 점검 필요 (재고/프로모션 불균형 가능성).
  4. AC=HA 정상 패턴: 거래선 자체가 건강 → 벤치마크 / 확장 검토 후보.
